
# 👗 AI Fashion Design Studio
A tool to generate high-fidelity clothing designs and source affordable matches.

## 🚀 Tech Stack
- **Image Generation:** Fal.ai (Flux.1)
- **Vision AI:** Google Gemini 1.5 Flash
- **Sourcing:** SerpApi (Google Shopping)
- **UI:** Gradio / Google Colab

## 🛠️ Usage
1. Open the `.ipynb` file in Google Colab.
2. Add your API keys to Colab Secrets (`FAL_KEY`, `GEMINI_API_KEY`, `SERP_API_KEY`).
3. Run all cells to launch the app.
